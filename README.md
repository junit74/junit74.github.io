# UNI-Way 웹사이트

빌드 과정이나 패키지 설치 없이 배포할 수 있는 한국어 정적 웹사이트입니다.

## 파일

- `index.html`: 스튜디오·게임 소개 및 문의
- `style.css`: 데스크톱·모바일 반응형 스타일
- `script.js`: 저작권 연도 갱신 (JavaScript 없이도 이용 가능)
- `privacy.html`: 웹사이트 자체의 개인정보 관련 기능 안내. **앱 개인정보처리방침이 아닙니다.**
- `favicon.svg`: 사이트 아이콘
- `.nojekyll`: GitHub Pages 정적 파일 배포용

## 공개 전 완료할 사항

1. 공개 고객지원 이메일은 사용자가 승인한 `junit74@gmail.com`입니다. 메일 링크를 반영했습니다.
2. 게임 제목과 스튜디오 소개를 확인합니다. 소개 그래픽은 실제 게임 화면이 아닙니다. 실제 스크린샷을 받으면 교체할 수 있습니다.
3. 사업자등록이 완료되면 최종 상호를 확인합니다. 사업자번호, 개인 주소 및 전화번호는 임의로 공개하지 않았습니다.
4. 앱의 실제 개인정보 수집·이용, SDK, 보관·삭제 방식 등을 확인한 후 **앱 전용 개인정보처리방침을 별도로 작성**합니다. 이 사이트의 개인정보 안내 주소를 앱 개인정보처리방침 주소로 등록하면 안 됩니다.
5. 호스팅은 GitHub Pages를 사용하며 사이트 안내에 해당 서비스 및 개인정보처리방침 링크를 반영했습니다.

## 로컬 미리보기

이 폴더에서 `python3 -m http.server 8765 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8765`를 엽니다. `index.html` 파일을 브라우저로 직접 열어도 작동합니다.

## GitHub Pages 배포

1. 사용자 소유 GitHub 계정에 `<계정명>.github.io` 공개 저장소를 만듭니다. 기존 저장소가 있으면 기존 내용을 먼저 확인합니다.
2. 이 폴더의 웹 파일들을 저장소 루트에 올립니다. README는 선택 사항입니다.
3. 저장소의 Settings → Pages에서 게시 브랜치와 `/(root)`를 선택합니다.
4. 배포가 성공하면 제공된 HTTPS 주소를 직접 확인합니다.

## Google 웹사이트 소유권 인증

1. Play Console 계정과 동일한 계정으로 Google Search Console에 로그인합니다.
2. URL 접두사 속성으로 **실제 배포 주소**를 등록합니다.
3. HTML 파일 인증을 선택하면 Google이 제공한 파일을 이름과 내용 변경 없이 사이트 루트에 추가하고 다시 배포합니다. HTML 태그 방식을 선택하면 Google이 발급한 태그를 `index.html`의 `<head>` 안에 넣습니다. 인증 토큰을 임의로 만들면 안 됩니다.
4. Search Console에서 소유권을 확인합니다. 인증 파일/태그는 이후에도 유지합니다.
5. Play Console → 개발자 계정 → 내 정보에 동일한 웹사이트 주소를 입력·저장한 후 확인 요청을 보냅니다.

이 파일을 만들었다는 것만으로 사이트가 인터넷에 배포되거나 Google 인증이 완료되는 것은 아닙니다.
