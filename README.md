# UNI-Way 웹사이트

공개 주소: https://junit74.github.io/

선택된 B 모노 스테이지 디자인을 사용하는 정적 웹사이트입니다. 빌드나 패키지 설치가 필요하지 않습니다.

## 구성

- `index.html`: 스튜디오, 실제 게임 화면 3장, 문의
- `privacy.html`: 웹사이트 개인정보 안내 (게임 앱 전용 정책과 별개)
- `style.css`: 흑백 디자인 및 모바일 반응형 스타일
- `theme.js`: 브라우저의 밝기 설정을 즉시 반영하고 변경 시 자동 전환
- `script.js`: 저작권 연도와 브라우저 테마별 파비콘 갱신
- `assets/`: 현재 사용하는 흑백 로고, 파비콘, 실제 게임 스크린샷과 출처
- `favicon.svg`, `.nojekyll`: 기본 사이트 아이콘 및 GitHub Pages 설정

화면 테마 선택 메뉴와 테마 설정 저장 기능은 없습니다. 게임 이미지는 원래 색상으로 표시합니다. 이전 디자인 시안과 미사용 에셋은 정리했습니다.

## 로컬 미리보기

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

http://127.0.0.1:8765/ 에서 확인할 수 있습니다. `main` 브랜치에 푸시하면 GitHub Pages가 배포합니다.

## Google 웹사이트 소유권 인증

Play Console 계정으로 Search Console에서 실제 사이트 URL을 등록하고, Google이 제공하는 인증 파일 또는 태그를 추가한 뒤 소유권을 확인해야 합니다. 인증이 완료되면 인증 파일/태그를 계속 유지하세요. 홈페이지 배포 자체가 Google 소유권 인증 완료를 의미하지는 않습니다.
